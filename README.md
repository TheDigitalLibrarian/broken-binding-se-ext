# Broken Binding Specials & Subscriptions Extension

A browser enhancement for [The Broken Binding](https://thebrokenbindingsub.com/). Today it
focuses on your account page — rewriting the built-in order history into a single, fast,
filterable view, with no clicking through pages. A better view for browsing the store is
planned.

Everything runs in your own browser, using the login you already have. Nothing is
sent anywhere except the shop's own site and two public exchange-rate APIs (for the
optional currency conversion). The only actions that ever change anything are the two
address controls on the Account tab, and only when you click them.

## What it does

- **One continuous list.** Every page of your order history is merged into a single
  view, so all your orders are in one place.
- **Summary card.** Total spent, order count, book count, average per order, and how
  far back your history goes — all recomputed live as you filter.
- **Per-order detail.** Expand any order to see covers, titles, authors, printing,
  shipping, and tracking numbers.
- **Grid view.** Every book you've ever ordered as a wall of covers, grouped by year
  and month, with best-fit thumbnails.
- **Filters.** By year, by month, by status (shipped, refunded, …), by free text, and
  a newest/oldest sort — in both the list and the grid.
- **Currency conversion.** See totals in your own currency, converted at the exchange
  rate *on each order's date* (ECB fixings via Frankfurter) or at today's rate. The
  basis picker hides itself for currencies that only support one.
- **Account tab.** Your saved shipping addresses as cards, with the ability to add or
  remove one — including the reminder that a new address doesn't change existing orders.
- **Private mode.** One click redacts every name, address, order number, tracking
  number, date, and price, so you can share your screen safely.

## Install

There are two ways to run it. Open **`dist/install.html`** in your browser for a guided
page with copy buttons for both — or follow the short version here.

### Userscript (recommended)

Runs by itself on the account page, and updates cleanly. Works with Tampermonkey,
Violentmonkey, or Greasemonkey (Firefox).

1. Install a userscript manager if you don't have one.
2. Open **`dist/broken-binding-se-ext.user.js`** — the manager offers to install it.
3. Visit `thebrokenbindingsub.com/account`. The extension loads automatically.

### Bookmarklet

No extension needed; you click it when you want it.

1. Open **`dist/bookmarklet.txt`** and copy the whole line.
2. Make a new bookmark and paste it as the URL (address/location).
3. On your account page, click the bookmark.

## Publishing the userscript

To share it publicly, [Greasy Fork](https://greasyfork.org/) is the usual home — sign
in with GitHub/Google, "Post script", paste `dist/broken-binding-se-ext.user.js`. The `@version`
header drives its update checks, so bump it on each release. GitHub (raw `.user.js`
URL) and OpenUserJS are alternatives. See CHANGELOG.md for the version history.

## Project layout

```
src/broken-binding-se-ext.js   The single source of truth (readable ES5).
templates/install.tpl.html   The install page shell (build fills it in).
build/build_user.py      Prepends the userscript header -> dist/broken-binding-se-ext.user.js
build/build.py           Builds dist/bookmarklet.txt and dist/install.html
build/package.ps1        Zips the userscript -> dist/broken-binding-se-ext-<version>.zip
dist/                    Built artifacts (regenerated by the build).
test/server.mjs          A fixture server mirroring the account page's DOM.
test/run.mjs             A headless-Chromium suite that drives the plugin.
```

`src/broken-binding-se-ext.js` is deliberately ES5 (no `let`/`const`/arrow/template strings) so the same
source ships as both the userscript and the minified bookmarklet.

## Building

Requires Python 3, Node, and [terser](https://github.com/terser/terser).

```
npm install          # dev deps: terser, acorn, playwright
npm run build        # -> dist/broken-binding-se-ext.min.js, .user.js, bookmarklet.txt, install.html
npm run check        # confirm src/broken-binding-se-ext.js is valid ES5
```

To bump the version, edit `@version` in `build/build_user.py` (and CHANGELOG.md), then
rebuild.

## Packaging a release

`build/package.ps1` (PowerShell, Windows) zips the built userscript into a
version-stamped archive for distribution:

```
.\build\package.ps1          # zip whatever is in dist/
.\build\package.ps1 -Build   # rebuild the userscript from src first, then zip
```

It reads the `@version` from `dist/broken-binding-se-ext.user.js` and writes
`dist/broken-binding-se-ext-<version>.zip` with the `.user.js` at the archive
root — the layout Greasemonkey, Tampermonkey and Violentmonkey expect. The same
thing is wired into npm:

```
npm run package      # -> dist/broken-binding-se-ext-<version>.zip
npm run release      # full build, then package
```

To cut a release: bump `@version` in `build/build_user.py` (and the version in
`package.json` and CHANGELOG.md), then run `npm run release`.

## Testing

The suite starts a local fixture server whose DOM matches the selectors the plugin
parses, loads it in headless Chromium, injects the plugin, and asserts behaviour —
private-mode redaction on rows merged mid-load, the failed-order path, month filtering
under a single-year badge, filter survival across a resize, quantity-aware book counts,
grid grouping and sort, add-form value preservation, and the address country default.

```
npm test
```

Playwright must be installed and a Chromium available. The exchange-rate APIs are
blocked during the run so the "couldn't fetch rates" path is exercised; no real order
or address is ever touched.

## Privacy & safety

- Read-only except the Add/Remove address buttons on the Account tab.
- Order and address data stays in your browser. The only outbound calls are to the
  shop itself and, for conversion, `api.frankfurter.dev` and `open.er-api.com`.
- Private mode is for screen-sharing; it redacts the display only and changes nothing.
